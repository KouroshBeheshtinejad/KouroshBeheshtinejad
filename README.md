## Advanced Malware & Ransomware Detection

A machine learning project focused on detecting malicious Windows Portable Executable (PE) files.

The project involved:

* Dataset preprocessing
* Feature engineering
* Multiple machine learning classifiers
* Model comparison
* Performance evaluation
* Malware classification
* ROC-AUC analysis

The final LightGBM model achieved approximately:

* Accuracy: **99.55%**
* Precision: **99.65%**
* Recall: **99.32%**
* F1 Score: **99.48%**
* ROC-AUC: **0.9998**

This project represents one of my main interests: applying machine learning to **real-world cybersecurity problems**.

# Engineering Philosophy

I believe strong AI engineering requires more than achieving a high score on a dataset.

My approach is centered around four principles:

**Understand the problem.**
Understand the mathematical, statistical, and domain foundations before selecting a model.

**Build the system.**
Move from experiments and notebooks toward reproducible, modular, maintainable software.

**Measure the result.**
Use appropriate evaluation metrics, validation strategies, error analysis, and meaningful baselines.

**Keep learning.**
Continuously bridge the gap between academic research, modern AI techniques, and production engineering.
